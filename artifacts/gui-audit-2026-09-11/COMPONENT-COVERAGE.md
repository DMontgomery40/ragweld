## Scope and method

- Current Mac source inventory: **128 TSX files**, **2477 literal opening div tags**, and **556 literal native button/input/select/textarea tags**. Repeated maps, portals, imported library widgets, conditional states, and CSS do not have a one-to-one relationship with these counts. These are source-scale indicators, not finding counts or a runtime DOM census.
- A read-only static scan resolves relative and `@/` imports, re-exports and literal dynamic imports through local .ts/.tsx/index files from `main.tsx`. All 128 TSX files appear in that module closure. Barrel imports and navigation/config cycles mean module reachability does **not** establish rendered reachability or route ownership. No file is being dismissed as dead UI on this evidence.
- The consumer column records actual immediate source importers. Family is a navigation aid based on the component's location and immediate use, not a transitive call-graph claim. The Mac source and deployed build may differ; browser evidence in [COVERAGE.md](COVERAGE.md) is authoritative for visible behavior.
- Every row starts **P = partial**: its family has browser evidence, but per-component conditional, focus, responsive, empty/error/success and Dock states are not exhaustively reconciled. A family visit does not upgrade each child to tested. **L = execution-limited** identifies result/rendering variants that require a job or unavailable run data; safe states still remain in scope.
- The next pass must inspect explicit state branches below, including repeated card layouts and nested editors, rather than stopping at the route checklist. Source-only concerns are not accepted visual findings until captured and inspected in the browser.

## Remaining state work by component family

- **Shared shell and Dock:** mode switching, chooser keyboard/focus, persistence, split allocation, main/Dock swap and main-context retention; each dockable route at narrow/medium/wide allocations. Desktop and Chat responsive checks are partial, not coverage of every docked component. Source viewer remains a powerful parallel workspace, not a panel to remove.
- **Documents:** PDF page/citation switching and evidence overlays inspected on two real pages; rich Markdown rendering, mixed figure/table citations, long cited-page ranges, source failure/retry, raw-document new-tab result and focus return remain. Do not fabricate documents or modify indexed sources to force these states.
- **Chat:** populated/empty history, sources, trace and settings inspected; attachment selection/preview/remove and export result remain. Streaming, retry/cancel, errors and answer alternatives require real run evidence or an authorized test fixture. No model request was issued for the audit.
- **Dashboard:** remaining cost/accounting row permutations, index/history drilldowns, terminal interactions, calculators' unit/focus/viewport behavior and each compact Dock variant. Existing failure/accounting rows must be used without starting jobs.
- **RAG Retrieval/Data Quality/Indexing:** prompt deep-link destinations, all nested source/model controls, intent-matrix rows, schema review's existing draft/applied/empty variants, run-cost disclosures, read-only estimate states when safely reachable, error recovery and compact layouts. No staging/apply, generation, indexing, schema acceptance or deletion merely for coverage.
- **RAG Graph:** community/entity/table/provenance and fullscreen states now inspected; entity search/filter/reset, empty matches, alternate source ranges, legend/hover/readable labels, accessible graph alternatives, exports and compact/fullscreen reflow remain. Fit and Escape work after settling; opening-animation captures are not accepted settled defects.
- **Training studios:** existing run selection, overview/diff, layout switches, visualizer and log pop-outs, detail tabs, renderer fallback, empty/failure/completed variants, download results and keyboard/focus. Do not mine, train, evaluate, promote or clear operator data merely to obtain states.
- **Synthetic Lab:** existing completed run detail, recipe/artifacts/quality/preview permutations, compare/reuse preparatory states, result download, and empty/error views. Publication, new generation and active-slot changes remain execution-limited.
- **Evaluation:** prompt navigation and reset confirmation without committing; dataset row expansion/edit cancellation; existing run selectors/comparison and question states; Promptfoo existing-result details; trace links; compact layouts. New evaluation, AI analysis, prompt save/reset and dataset changes remain execution-limited.
- **Benchmark:** existing catalog/filter/preflight inspected; the actual ResultsTable, SplitScreen, CostAttribution and PipelineProfile need saved results or approved runs. Never mark them rendered from a static import.
- **Infrastructure/Observability:** log/modal focus, log tabs and read-only details, external destination semantics, card/table compact layouts and existing incidents. Restart/stop/probe and connection/config writes remain out of the audit's authorization.
- **Admin/shared fields:** 454 current registry settings create repeated controls; category coverage must track type, constraints, inheritance, disabled/dependent states, raw-section edit cancellation, keyboard labeling and dirty-state visibility. Do not apply configuration to test persistence. Generic tooltip/loading/error/confirmation components need distinct instance context, not one screenshot as universal approval.
